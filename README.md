# SIGITSE

Sistema de Gestión Digital del Trámite de Inspección Técnica de Seguridad en Edificaciones (ITSE Básica).

Proyecto académico del curso de Ingeniería de Software, con la Municipalidad Distrital de San Miguel como piloto referencial.

## Descripción

SIGITSE digitaliza el flujo administrativo del trámite de ITSE Básica: solicitud en línea, validación documentaria, registro de pago, asignación y agenda del inspector, checklist digital de inspección en campo, generación automática del Certificado de ITSE y notificación al administrado.

La visita de inspección sigue siendo presencial y la realiza un inspector acreditado. El sistema no la reemplaza, solo digitaliza el proceso administrativo alrededor de ella.

## Stack Tecnológico

- Frontend: React + TypeScript + Vite
- App del inspector: React + TypeScript + Vite (PWA)
- Backend: NestJS + TypeScript
- ORM: Prisma
- Base de datos: PostgreSQL
